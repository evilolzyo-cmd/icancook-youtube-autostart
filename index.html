ICANCOOK
YouTube Autostart

A local tool that prepares a YouTube broadcast when the ICANCOOK account owner starts a Twitch stream in OBS.

What it does

The tool runs on the account owner's Windows computer. With the owner's Google authorization, it identifies the configured YouTube stream, prepares a public broadcast using the latest broadcast title and description, and starts the YouTube encoder output through the existing OBS connection.

It checks YouTube's broadcast status separately from the OBS connection so that sending video is not mistaken for being publicly live.

Account access

Google authorization is handled by Google's own sign-in and consent pages. This website does not accept passwords, stream keys, or Google authorization codes. The desktop app receives its authorization callback on the account owner's computer.

This is a personal utility for the ICANCOOK account owner. There is no public registration or hosted streaming service.

Contact

The owner can be reached through the public ICANCOOK Twitch channel.
