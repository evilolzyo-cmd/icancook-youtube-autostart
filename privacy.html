Privacy notice

How the current local tool uses the account owner's YouTube authorization.

Information used

The tool reads the authorized channel ID, owned live-stream configuration, broadcast metadata and broadcast status. It uses this information to identify the configured ICANCOOK stream, reuse broadcast details, and create, bind and start a YouTube live broadcast.

The existing OBS configuration supplies the YouTube stream key locally. The key is used to match the correct owned stream and is not published on this website.

Local storage

Google OAuth client information and account authorization tokens are saved on the owner's Windows computer using encryption tied to the Windows user account. Local status files contain operational details, such as whether the encoder is connected and whether YouTube confirmed that the broadcast is live.

The helper's status output does not include access tokens, refresh tokens, passwords or stream keys.

Sharing and Google access

Authenticated requests are sent to Google's OAuth and YouTube APIs to perform the requested broadcast operations. This tool does not provide an advertising, data-sale or third-party data-sharing service.

Google's consent screen describes the available YouTube video-management permission. The current helper implements channel and stream reads, broadcast creation and binding, and broadcast-start transitions. It has no video-deletion operation.

Use of Google data by this tool follows the Google API Services User Data Policy, including the Limited Use requirements.

Control and removal

The owner can revoke the app's access from Google Account connections. The owner can also disable the ICANCOOK YouTube autostart task in Windows Task Scheduler and remove the local encrypted credential file to stop local access.

Removing local files does not delete any YouTube video. YouTube's own account controls govern retention and removal of published broadcasts.

This website

This static information site has no sign-in form, advertising or analytics scripts. Its hosting provider may process ordinary web-request information under its own privacy terms.
